1. RINGKASAN EKSEKUTIF APLIKASI
--------------------------------------------------------------------------------
SM-Learning DIKMAS POLRI adalah platform digital terpadu pendidikan keselamatan
berlalu lintas dan kesadaran hukum masyarakat. Sistem ini menggabungkan:
1. Pembelajaran mandiri berbasis modul interaktif, video, infografis, dan kuis.
2. Fasilitas kegiatan sosialisasi lapangan (Trainer Outreach) oleh 34 Polda se-Indonesia.
3. Penerbitan dan verifikasi QR-Code sertifikat digital kelulusan otomatis.
4. Portal pembelajaran terbuka bagi masyarakat dan pelajar tanpa wajib login (/umum).
5. Dashboard analitik eksekutif berjenjang 3 level (Nasional, Polda, Polres).
6. Penyimpanan data berbasis MySQL relasional resmi (sm_learning).

3. SETUP BASIS DATA MYSQL (XAMPP / PHPMYADMIN / SERVER)
--------------------------------------------------------------------------------

1. File Skema:
   File `schema.sql` berada di root folder proyek. Berisi seluruh definisi tabel:
   - polda, polres (master wilayah dari data_polda & data_polres)
   - roles, users (pengguna & RBAC)
   - materials (katalog materi, modul, silabus, bank soal)
   - user_progress, user_bookmarks, user_history, quiz_attempts, certificates
   - outreach_sessions, session_participants, outreach_reports, learning_events

2. Cara Migrasi & Seeding Data Awal:
   Opsi A (CLI / Terminal):
     npm run db:migrate

   Opsi B (phpMyAdmin):
     - Buka http://localhost/phpmyadmin
     - Buat database baru bernama `sm_learning`
     - Pilih menu "Import" dan upload file `schema.sql`
     - Jalankan aplikasi (`npm start` atau `npm run dev`) — sistem otomatis
       melakukan seeding master wilayah dan 72 akun pengguna jika tabel masih kosong.

3. Variabel Lingkungan (.env):
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD=
   DB_NAME=sm_learning
